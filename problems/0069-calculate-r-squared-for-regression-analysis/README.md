# 69. 计算决定系数（R²）

## 1. 题目理解

计算回归模型的决定系数（Coefficient of Determination，R²），用于衡量模型的预测效果。

R² 通过比较模型预测误差与均值预测误差，衡量模型对真实数据变化的解释程度。

## 2. 核心思路

### 2.1 数学公式

`R² = 1 - SSR / SST`

其中：

- SSR：残差平方和，衡量模型预测产生的误差。
- SST：总平方和，衡量直接使用真实值均值进行预测产生的误差。

残差平方和：

`SSR = Σ(yᵢ - ŷᵢ)²`

总平方和：

`SST = Σ(yᵢ - ȳ)²`

其中：

- yᵢ：真实值。
- ŷᵢ：预测值。
- ȳ：真实值的均值。

### 2.2 与 MSE 的关系

由于分子和分母同时除以样本数量 n，R² 也可以表示为：

`R² = 1 - MSE_model / MSE_baseline`

其中：

- MSE_model：模型预测的均方误差。
- MSE_baseline：使用真实值均值进行预测的均方误差。

两种计算方式完全等价。

## 3. 本题知识点

### 3.1 R² 的取值含义

| R² | 含义 |
|---|---|
| 1 | 模型预测完全正确 |
| 0.9 | 相比均值预测，减少了 90% 的平方误差 |
| 0 | 模型与均值预测效果相同 |
| 小于 0 | 模型预测效果不如均值预测 |

当真实值存在变化时，R² 的取值范围为 (−∞, 1]。

### 3.2 R² 的核心理解

假设直接使用均值进行预测，产生的平方误差为 100，而模型预测产生的平方误差为 20。

`R² = 1 - 20 / 100 = 0.8`

说明模型相比均值预测减少了 80% 的平方误差。

因此，R² 衡量的是模型相对于均值预测这一基准的改进程度，而不是预测准确率。

### 3.3 R² 的特点

- 无量纲，不受数据单位影响。
- 数值越接近 1，表示模型在当前数据上的预测效果越好。
- R² 可以为负数。
- 较高的训练集 R² 不代表模型具有较好的泛化能力。
- 当真实值全部相同时，SST 为 0，原始公式无法直接计算，需要特殊处理。

### 3.4 常见回归评价指标对比

| 指标 | 衡量内容 | 理想值 | 量纲 |
|---|---|---|---|
| MAE | 平均绝对误差 | 0 | 原始量纲 |
| MSE | 平均平方误差 | 0 | 原始量纲的平方 |
| RMSE | 均方根误差 | 0 | 原始量纲 |
| R² | 相对于均值预测的改进程度 | 1 | 无量纲 |

## 4. 总结

R² 是衡量回归模型预测效果的常用评价指标。

核心公式：

`R² = 1 - SSR / SST`

核心理解：

R² 衡量模型相比直接使用均值进行预测，减少了多少比例的平方误差。

MSE、RMSE 和 MAE 衡量预测误差的大小，而 R² 衡量模型相对于基准预测的改进程度。
