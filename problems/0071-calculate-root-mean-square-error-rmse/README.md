# 71. 计算均方根误差（RMSE）

## 1. 题目理解

计算真实值与预测值之间的均方根误差（RMSE）。

题目要求：

- 支持一维和二维 NumPy 数组。
- 数组形状不同或数组为空时，抛出 `ValueError`。
- 返回结果保留三位小数。

## 2. 核心思路

RMSE 的计算公式：

`RMSE = √[Σ(yᵢ - ŷᵢ)² / n]`

其中：

- yᵢ：真实值。
- ŷᵢ：预测值。
- n：数组中的元素总数。

RMSE 本质上就是对 MSE 开平方：

`RMSE = √MSE`

计算过程：计算误差 → 平方 → 求平均值 → 开平方。

## 3. 本题知识点

### 3.1 shape、size 与 len 的区别

对于一个形状为 (2, 3) 的二维数组 `arr`：

| 属性或函数 | 含义 | 结果 |
|---|---|---|
| `arr.shape` | 数组形状 | (2, 3) |
| `arr.size` | 元素总数 | 6 |
| `len(arr)` | 第一维长度 | 2 |

使用 `shape` 检查数组形状，避免广播机制导致错误计算；使用 `size` 判断数组是否为空。

### 3.2 主动抛出异常

`raise ValueError` 用于在输入不符合要求时主动抛出异常，终止函数的正常执行。

### 3.3 RMSE 的特点

- 取值范围为 [0, +∞)。
- 数值越小，预测误差越小。
- 相比 MAE，对较大的预测误差更加敏感。
- 与原始数据具有相同的量纲，更容易解释。

### 3.4 MSE 与 RMSE 的区别

| 对比项 | MSE | RMSE |
|---|---|---|
| 中文名称 | 均方误差 | 均方根误差 |
| 计算方式 | 误差平方后取平均值 | MSE 开平方 |
| 量纲 | 原始量纲的平方 | 原始量纲 |
| 理想值 | 0 | 0 |

## 4. 总结

RMSE 是回归模型的常用评价指标，通过对 MSE 开平方，使误差恢复到原始数据的量纲。

本题重点掌握：

- RMSE 的计算原理及其与 MSE 的关系。
- `shape`、`size` 和 `len()` 的区别。
- 使用 `raise ValueError` 处理非法输入。
- `np.mean()` 默认对所有元素求平均值，无须区分一维和二维数组。
