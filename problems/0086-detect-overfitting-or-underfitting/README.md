# 86. 检测过拟合或欠拟合

## 1. 题目理解

根据模型在训练集和测试集上的准确率，判断模型的拟合状态。

| 模型状态 | 返回值 |
|---|---|
| 过拟合（Overfitting） | 1 |
| 欠拟合（Underfitting） | -1 |
| 良好拟合（Good Fit） | 0 |

## 2. 核心思路

题目规定的判断规则：

- 过拟合：训练准确率减去测试准确率大于 0.2。
- 欠拟合：训练准确率和测试准确率均小于 0.7。
- 良好拟合：上述两个条件均不成立。

必须优先判断过拟合，再判断欠拟合。

注意：0.2 和 0.7 是出题者设定的阈值，并不是机器学习中的通用判断标准。

## 3. 本题知识点

### 3.1 过拟合（Overfitting）

模型过度学习了训练数据中的细节和噪声，导致泛化能力较差。

典型特征：

- 训练误差低，测试误差高。
- 低偏差、高方差。
- 模型通常过于复杂。

常见解决方法：

- 增加训练数据。
- 使用正则化。
- 降低模型复杂度。
- 使用早停法（Early Stopping）。

### 3.2 欠拟合（Underfitting）

模型没有充分学习数据中的规律，导致训练集和测试集上的表现都较差。

典型特征：

- 训练误差高，测试误差高。
- 高偏差、低方差。
- 模型通常过于简单。

常见解决方法：

- 提高模型复杂度。
- 增加有效特征。
- 适当增加训练次数。
- 减小正则化强度。

### 3.3 三种拟合状态对比

| 对比项 | 欠拟合 | 良好拟合 | 过拟合 |
|---|---|---|---|
| 训练误差 | 高 | 低 | 低 |
| 测试误差 | 高 | 低 | 高 |
| 模型复杂度 | 过低 | 适中 | 过高 |
| 偏差 | 高 | 较低 | 低 |
| 方差 | 低 | 较低 | 高 |
| 泛化能力 | 差 | 好 | 差 |

### 3.4 泛化能力（Generalization）

泛化能力是指模型在未见过的数据上的预测能力。

训练集表现好，并不意味着模型的泛化能力强。模型不仅需要学习训练数据，还需要掌握数据背后的普遍规律。

## 4. 总结

- 欠拟合：没有充分学到数据规律。
- 过拟合：过度学习了训练数据的细节和噪声。
- 良好拟合：学到了有效规律，并具有较好的泛化能力。

机器学习的目标并不是单纯降低训练误差，而是在偏差与方差之间取得平衡，从而降低模型在未知数据上的预测误差。
